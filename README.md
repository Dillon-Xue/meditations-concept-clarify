# 概念提纯炉·定义锻造 （`meditations-concept-clarify`）

> 来源：《第一哲学沉思集》(笛卡尔) · 用「一盏神灯」蒸馏的技能包

## 这是什么
“自由”“好产品”越想越糊涂？用猜想—反驳循环把模糊概念提纯成清晰定义。

## 触发场景（说出这些，技能即被加载）
- 这个概念到底指什么
- 怎么把定义说清楚
- 词语越解释越乱怎么办

## 怎么用
在对话里描述上述场景，WorkBuddy 会按 SKILL.md 的 description 匹配并加载本技能，引导你走对应方法论。
技能自带“边界”提示（哪些情况不要用），避免硬套模板。
